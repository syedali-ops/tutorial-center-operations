# Test Paper Planning (Sample)

## Purpose
Plan tests that match the syllabus and show where students need help.

## Steps
1. Map the syllabus into units and chapters.
2. Set the test date, duration and total marks.
3. Distribute marks across topics according to their weight in the syllabus.
4. Set a mix of easy, medium and hard questions.
5. Review the paper against the syllabus before it is used.
6. After the test, record marks and note weak topics.

| Topic | Marks | Question type |

- [ ] Covers only taught topics
- [ ] Marks add up correctly
